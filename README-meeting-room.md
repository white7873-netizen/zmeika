# 📅 Планировщик переговорки

Одностраничное приложение для бронирования **одной переговорной комнаты**.
Работает полностью в браузере — **без сборки, без сервера, без зависимостей**.

## Как запустить

Просто откройте файл `planner.html` в любом современном браузере
(двойной клик по файлу или «Открыть в браузере»).

```
planner.html  ← запускать этот файл
planner.css   ← стили
planner.js    ← логика приложения
```

## Возможности

- **Дневной вид** — часовая сетка с 08:00 до 21:00; клик по слоту (точность — 30 минут) открывает форму новой встречи. Красная линия показывает текущее время.
- **Недельный вид** — все брони за неделю; клик по дню переключает на дневной вид.
- **Список** — все предстоящие бронирования с быстрым удалением.
- **Форма встречи**: дата, начало/окончание, название, организатор, участники, заметка, цвет метки.
- **Защита от конфликтов** — нельзя забронировать время, пересекающееся с существующей встречей; при попытке показывается список конфликтующих броней.
- **Редактирование и удаление** — клик по карточке встречи открывает её в модалке.
- **Статистика дня** — количество встреч и суммарные часы занятости.
- **Навигация** — кнопки ‹ / Сегодня / ›, а также стрелки ← → на клавиатуре, `Esc` закрывает окно.
- **Хранение** — данные сохраняются в `localStorage` браузера (переживают перезагрузку страницы). При первом запуске добавляются демо-встречи.
- Адаптивная вёрстка (десктоп / планшет / телефон).

## Сброс данных

Очистите `localStorage` (ключ `meeting-room-bookings-v1`) в инструментах разработчика браузера — и приложение снова покажет демо-расписание.
